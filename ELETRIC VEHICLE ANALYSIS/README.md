# Hotel Revenue Analysis

## This project transforms transactional sales data into actionable business insights using Power BI. The objective is to analyze sales performance, identify trends, evaluate product and category performance, monitor KPIs, and support data-driven business decisions.

## The dataset contains fields such as Order ID, Date, Product, Category, Quantity, Revenue, Customer, and Location. Suitable datasets include Superstore Sales, Online Retail, or Pizza Sales.

## The data was cleaned and transformed using Power Query by handling missing values, duplicates, incorrect data types, and inconsistent categories. A structured data model was created, followed by DAX measures for Total Revenue, Orders, Quantity Sold, Average Order Value, Profit, and Sales Growth. Exploratory analysis was performed to identify trends and performance patterns before building an interactive Power BI dashboard.

## The dashboard provides insights into revenue trends, peak sales periods, top and underperforming products, category performance, and areas requiring attention. Interactive slicers allow users to explore results by time, product, category, and other dimensions.

## Key KPIs include Total Revenue, Total Orders, Quantity Sold, Average Order Value, Profit, Profit Margin, Sales Growth, and Product Contribution.

# The analysis can help businesses prioritize high-performing products, investigate underperforming categories, optimize inventory, improve promotional strategies, and monitor declining performance.

## Tools used: Power BI, Power Query, DAX, SQL, and Excel/CSV.

## This project demonstrates the complete data analytics lifecycle, from data cleaning and modeling to visualization, insight generation, and business recommendations. It showcases practical skills in data analysis, business intelligence, Power BI, and data storytelling.
