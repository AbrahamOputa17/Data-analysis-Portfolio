# Air Quality Index (AQI) Analysis Dashboard

## This project analyzes Air Quality Index (AQI) data to identify pollution patterns, high-risk locations, major pollutants, and changes over time. Using Power BI, environmental data is transformed into an interactive dashboard that helps stakeholders monitor air quality and make data-driven environmental and public-health decisions.

## The objective is to compare AQI across locations and periods, identify unhealthy pollution levels, determine contributing pollutants, and provide actionable recommendations. Potential datasets include Kaggle AQI datasets, OpenAQ, WHO air-quality data, and government monitoring stations, containing fields such as date, location, AQI, PM2.5, PM10, NO₂, SO₂, CO, O₃, temperature, and humidity.

## The workflow involves data collection, cleaning missing values and duplicates, standardizing formats, transforming variables, exploratory analysis, DAX calculations, visualization, and insight generation. Key KPIs include average AQI, maximum AQI, unhealthy-air days, pollutant concentration, AQI trends, and location performance.

## Key questions include: Which locations have the highest AQI? Which pollutants contribute most to poor air quality? When are pollution levels highest? Are there seasonal trends? Which areas consistently exceed safe thresholds?

## Recommended visuals include KPI cards, line charts, bar charts, maps, heatmaps, pollutant comparisons, slicers, and drill-through pages.

## Insights can support recommendations such as increasing monitoring in high-risk areas, investigating pollution sources, issuing public-health alerts, and strengthening pollution-control measures.

## This project demonstrates practical skills in data cleaning, exploratory analysis, DAX, Power BI visualization, dashboard development, and business storytelling using Power BI, Power Query, Excel/CSV, SQL, and Python.
