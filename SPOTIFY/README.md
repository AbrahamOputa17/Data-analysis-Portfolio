# SPOTIFY

## This project analyzes Spotify music data using Power BI to understand song, artist, album, and popularity performance. The goal is to transform raw music data into actionable insights that support playlist creation, artist promotion, content strategy, and business decisions. The analysis assumes data containing track names, artists, albums, release dates, popularity, streams, duration, genres, and explicit-content indicators.

## Key insights include identifying top-performing songs and artists, analyzing popularity trends, comparing albums and singles, and examining factors associated with song performance. KPIs include total tracks, unique artists, average popularity, total streams, top-performing songs, average duration, explicit-content percentage, and popularity trends.

## Potential datasets include Spotify data from Kaggle, Spotify charts, or the Spotify API. Key questions include: Which songs and artists perform best? What factors influence popularity? Which genres or album types perform better? How does performance change over time? Which emerging artists show growth potential?

## The workflow involves data collection, cleaning duplicates and missing values, transformation, data modeling, DAX calculations, exploratory analysis, visualization, validation, insight generation, and recommendations.

## Recommended dashboard visuals include KPI cards, Top-N bar charts, trend lines, donut charts, scatter plots, tables, slicers, filters, and drill-through pages.

## Business recommendations include prioritizing successful and emerging artists, using trends to improve playlists and promotions, monitoring genre performance, and regularly refreshing the dashboard.
