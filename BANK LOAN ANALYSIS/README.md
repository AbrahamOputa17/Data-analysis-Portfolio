# Employee Performance Analysis

## This project analyzes bank loan data to understand lending performance, repayment behavior, and credit risk. The objective is to provide management with clear insights for improving lending decisions and monitoring portfolio health.

## The analysis examines loan applications, funded amounts, repayments, loan status, interest rates, DTI, employment, home ownership, loan purpose, loan term, borrower grade, verification status, location, and monthly trends. Loans are grouped into good loans (Fully Paid/Current) and bad loans (Charged Off).

## A suitable dataset would contain loan ID, loan amount, issue date, payment amount, interest rate, DTI, grade, purpose, employment length, state, home ownership, and loan status.

## The workflow includes data collection, cleaning, handling missing values and duplicates, correcting data types, exploratory analysis, KPI calculation, SQL analysis, borrower segmentation, visualization, dashboard development, and business recommendations.

## Key KPIs include Total Applications, Funded Amount, Amount Received, Average Interest Rate, Average DTI, Good Loan %, Bad Loan %, Default Rate, Recovery Rate, and MoM Growth.

## Key questions include: Which borrower groups have the highest default rates? Which loan purposes create the most risk? How does performance change over time? Which locations have the highest exposure? What borrower characteristics influence repayment?

## Recommended visuals include KPI cards, monthly trend charts, loan-status charts, maps, purpose and term charts, borrower-segment visuals, tables, matrices, and interactive filters.

## Recommendations include improving credit assessment, monitoring high-risk segments, applying risk-based pricing, reviewing lending policies, and developing predictive models for default risk.
