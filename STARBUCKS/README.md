# STARBUCKS

## This project analyzes Starbucks sales data to transform raw transactional records into actionable business insights using SQL and Power BI. The main objective is to evaluate sales performance, identify high-performing products and periods, understand purchasing patterns, and support data-driven decisions that can improve revenue and operations.

## The dataset can contain transaction dates, products, categories, quantities, prices, stores, locations, and revenue. The analysis involves collecting and cleaning the data, correcting data types, handling missing or inconsistent values, creating calculated fields, modeling the data, and developing DAX measures. Exploratory analysis is then used to identify trends, patterns, and performance differences.

## Key metrics include total revenue, total transactions, units sold, average transaction value, revenue growth, sales by product, category, store, and time period. Important questions include: Which products generate the most revenue? Which categories perform best? When are sales highest? Which stores or products underperform? How are sales changing over time?

## Recommended visuals include KPI cards, monthly sales trends, product and category bar charts, store-performance charts, and interactive filters for dates, products, categories, and locations.

## Business recommendations include promoting high-performing products, investigating weak-performing products or stores, optimizing inventory and staffing around peak periods, using purchasing patterns for targeted promotions, and continuously monitoring sales KPIs.

## The project demonstrates an end-to-end analytics workflow: data collection, cleaning, SQL analysis, data modeling, DAX calculations, visualization, insight generation, and business recommendations. Tools used include SQL, Power BI, DAX, Power Query, and Excel. It showcases practical skills in data analysis, business intelligence, dashboard development, and data storytelling.
